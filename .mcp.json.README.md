# Playwright MCP

`.mcp.json` registers a Playwright MCP server for this project.

**Why:** several times in this project a Server Action / form-submit bug could
not be reproduced without a browser, and the `claude-in-chrome` tools drive the
*user's own* Chrome session — not always connected, and not safe to automate
against while the user is working in it. Playwright MCP starts its own isolated
headless Chromium instead.

`--isolated` means no profile is persisted between runs, so nothing leaks into
(or out of) the user's browser.

## First-time setup

Claude Code asks for approval the first time a project `.mcp.json` is loaded.
Approve it, then install the browser binary once:

```bash
npx -y playwright install chromium
```

Check it registered:

```bash
claude mcp list
```

## Using it

Point it at the local dev server (`npm run dev`, http://localhost:3000). The dev
database is reached through an SSH tunnel that needs to be up first:

```bash
ssh -i ~/.ssh/hhm_shop_deploy_key -f -N -L 127.0.0.1:5434:127.0.0.1:5434 root@185.208.227.129
```

If the tunnel wedges (page hangs, "network error" in the browser), kill the old
process and re-run that command — see FEJLESZTESINAPLO.md.
